# @cpdd/ui

Biblioteca de componentes UI compartilhados para o projeto CPDD, construída com Preline.

## Uso no monorepo

Este package é consumido automaticamente via workspace do pnpm. Mudanças são refletidas instantaneamente via hot reload.

## Desenvolvimento

O package exporta componentes TypeScript diretamente (sem build), permitindo hot reload instantâneo no Next.js.
